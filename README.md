## What you'll find here

Each project includes a **"Why this exists"** section covering the problem, my approach, and the trade-offs I made. I care as much about the decisions as the output.

## How I think about product

- Start with the customer problem, then the metric, then the solution
- Frameworks should be usable on a Tuesday, not just look good in a deck
- Write down the decision and the reasoning, so the team can learn from both
